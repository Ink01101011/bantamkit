## Deviations from the plan
1. Lone surrogates: the plan's Python `encode("utf-8", "surrogatepass")` hashes CESU bytes Node never
   writes. Instead of a fallback-visible case (needs Task 2), the key is made identical: Python
   round-trips through UTF-16 with `replace` (`_node_utf8`), which is exactly Node's rule (pair -> code
   point, lone -> U+FFFD). Verified on 4 strings both sides before writing; pinned by the text_key case
   (two lone-surrogate facts, texts sent as plain JSON, not base64) and M1d.
2. Canonical head: `"dim":2.0` is a float to Python (refused) and an int to JSON.parse (read). Both sides
   now refuse a head whose bytes differ from `dumps`/`dumpIndex` of itself. Pinned by the corrupt-files case.
3. The suite's LCG runs over BigInt: `x * 1103515245` overflows 2**53 as a double, so the plan's recurrence
   was not what a Number LCG computes.
4. Node `VectorCache` exposes `size` (getter), Python `len()`.
