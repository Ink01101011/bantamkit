## Script
`.shiftwork/notes-job72/J72-14-rescore.py`, a variant of `J72-2-rescore.py` / `J72-7-rescore.py` `rescore`
(J72-2's `jl`, `write_jl`, `merge` and `score_pooled.score` are imported, not copied).
- Earlier pool: `pool-{targets,labels}-merged.jsonl` (J72-2's, 258 target names, 97 positives), re-derived from
  #199 + J71-5 + J72-3 and asserted unchanged.
- New targets: `J72-13-judge-targets.q*.jsonl`, asserted byte-equal to `J72-11-judge-targets.q*.jsonl`.
- New labels: `J72-13-labels.q*.jsonl` from `--labels-dir` (default notes-job72).
- Asserts before writing (and again on the read-back files): one label row per target row, no stray label row; each
  new positive is a new candidate; new candidates disjoint from gold candidates and the earlier pool; NO EARLIER LABEL
  CHANGES (per id, merged positives within the earlier judged set equal the earlier positives; earlier target order kept).
- Writes `pool-{targets,labels}-merged-j72-13.jsonl` to `--out-dir` (default notes-job72).
- Scores exactly `B_shipped` (notes-job71 `pool-injections-embed.json`) and `W10` (`J72-10-gold-inject-W10.json`).
  Refuses while any injected pair of either view is unjudged; no override flag.
- Prints the table, the bar line (margin read from `tools/eval/recall/bar.json` `embedding`; the file is only read),
  and one JSON line. A pass reads `PASS (UNVALIDATED)`.
