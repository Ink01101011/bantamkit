## Q9 — latency on the real Node hook: **MISS**

`node $P/J72-28-scripts/lat28.mjs $S 11` (detached, `> $S/lat28-run1.out`). Setup:
- The real `tools/hooks/bantamkit-hook.mjs`, spawned per run, 60 dev prompts, 11 runs each, the median per prompt,
  then p50/p90/max over prompts. Node v25.2.1, this machine.
- Three arms on one bed, interleaved per prompt:
  - **main** = 2eb426b, built from `git archive 2eb426b` in `$S/main` (`npm ci && npm run build && npm run sync-assets`)
  - **nosc** = this branch with the queries dir moved away
  - **sc** = this branch with the 5 sidecars, re-keyed byte for byte to the bed's store roots
- The bed: the project store is found by the cwd walk, the profile store is `~/.bantamkit/memory`, and the native
  store is found from `transcript_path`'s `memory/`.
- The transcript is a synthetic 309,832-byte fixture (no private text) whose last main-chain prompt lies inside the
  tail, so short prompts take the head on both branch arms.
- **indexed** = one discarded warm run, then the hot index stays. **unindexed** = the index dir is removed before
  every timed run.

| ms | main p50 / p90 / max | nosc p50 / p90 / max | sc p50 / p90 / max | rise nosc (p50 of per-prompt diffs / diff of p50s) | **rise sc** |

- **Bar (Q9): p50 rise ≤ 5 ms. The sidecar arm MISSES by about 3.5×.** The no-sidecar arm rises 2.3–3.1 ms. That is
  the head (one 256 KiB tail read plus a longer BM25F query), within the bar, but it is not ≈ 0.
- Every arm recalled on every run. Hook-log tallies for indexed mode: main 185 inject / 442 suppress / 22 none, nosc
  185 / 475, sc 180 / 480. Main's 22 `none:empty-no-match` are short prompts that the head lets match on the branch.

## Deviations
1. **Open question 8, measured:** 1 name clash, 440 of 441 keys land, and the clash key is never pooled.
2. **Head agreement** is measured on transcripts cut at the prompt (before and after its record). On the whole file
   the tail is the session's end, not what the hook saw. Whole-file counts are kept for reference.
3. **"unindexed" for the real hook** means a cold hot-index build on every run. No switch disables the index:
   `indexed()` refreshes it on each recall.
4. **main is built from `git archive`** in scratch rather than a git worktree, so no shared worktree metadata was
   touched.
5. **Sessions repeat:** each (arm, prompt) has a fixed `session_id`, so runs 2..11 suppress what run 1 injected. The
   recall still runs before suppression, and this is the same on every arm.
