## Decision and seam
Normalise, don't refuse (posted to #212). Rule = Node's UTF-8 encoder: each lone surrogate → one U+FFFD. Python:
`text.encode("utf-16-le", "surrogatepass").decode("utf-16-le", "replace")`, only when a surrogate is present. It also
JOINS a pair: PyYAML decodes `"😀"` as two code points (verified: `len == 5` for `"😀 a\ud800"`),
JS holds one emoji; after the rule both hold U+1F600. Reversed halves → two U+FFFD on both sides.

The only source of a surrogate in a fact is a YAML escape (files are read as strict UTF-8 on Python, TextDecoder on
Node), so the fix is at the frontmatter READ, the one seam every downstream writer reads from:
- Python `runtime-py/src/bantamkit/memory/store.py:49` `load_frontmatter` (store `_read_fact`, hot index `_secondary`)
  → `well_formed_value` (store.py:105 `well_formed`, :122 `well_formed_value`: str, list items, dict keys+values);
  `runtime-py/src/bantamkit/memory/divergence.py:551` `parse_fact` (native shape).
- Node `runtime-ts/src/memory/factfile.ts` `parseFrontmatter` → `wellFormedMeta` / exported `wellFormed`;
  `parseNativeFront` (hotindex.ts) goes through `parseFrontmatter`, so it is covered.
- Save path unchanged: `MemoryStore.save` already refuses a lone surrogate (#160) on both sides, and
  `mcpstdio.lone_surrogate_argument` / `pyargs.loneSurrogateArgument` refuse it at the MCP layer. Hook prompts are
  query text and already use `surrogatepass` (hookadapter.py:2619, hotindex.py:124 `shard_of`).
