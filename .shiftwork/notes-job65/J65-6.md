## 2. What changed (both runtimes, same sentences)

- **#123.** `_stamp`/`stamp()` write is best-effort. An `OSError`/`PyOSError` from the write is
  swallowed, the hits are answered, and the file keeps its old date. The temp is removed by the
  #161 cleanup. Silent, which the brief allows ("at most a degraded note"); see open question 1.
  The snapshot-scope listing raise is NOT swallowed
  (`test_a_recall_pinned_before_the_store_broke_answers_but_never_dates_it` is unchanged and green).
- **#141.** `NOT_WRITABLE_ERRNOS = {EACCES, EPERM, EROFS}` (TS `NOT_WRITABLE_CODES`). Two arms:
  (a) `_ensure_dirs`: the mkdir failed with one of those AND `self.root` is a directory that is
  there (`_present()`: `is_dir()`, with "could not stat" counted as there). (b) `save`: the fact
  write failed with one of those. Either way the refusal is
  `memory store is not writable: <root>: <strerror>; the directory exists but cannot be written to, so nothing was written`.
  "could not be created … is not there" is kept for a root that is not there, including cwd `/`,
  whose errno differs per platform (EROFS/ENOENT/EACCES). That is why the errno alone is not the test.
  `recall-strings`' pinned sealed sentence (a 555 parent, root absent) is unchanged and green.
- **#161.** `_write_fact`/`writeFact` write `<name>.md.<pid>.<8 hex>.tmp`, opened exclusively
  (`"x"` / `wx`), rename onto the fact, and unlink the temp on any failure. This is the J65-1/J65-4 shape.
  `*.md` listings never see it. Last writer wins on the rename.
- **#159.** The `read_text`/`pyReadText` moved inside `_facts`' try. `UnicodeDecodeError` is a
  `ValueError`, so it becomes `malformed fact file <name>: 'utf-8' codec can't decode …` (the
  decoder text kept verbatim). An `OSError` from the read still escapes as itself.
- **#184.** `load_grants`/`loadGrants`: `granted store is not a directory: <path> (from <config>)`
  when the path exists, and the old `does not exist` sentence otherwise.

After-probe (`<S>/probe-after.txt`, every row identical across runtimes): 555 recall answers
