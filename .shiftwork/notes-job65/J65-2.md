## 2. The properties held, and where each is pinned

(a) #121 — an unquoted `created:`/`last_recalled:` timestamp never crashes compact or recall:
`_facts`/`facts()` read a YAML date or datetime as its `str()` (`isoformat()` for a date,
`isoformat(' ')` for a datetime — the text the port already carries as the scalar's `text`,
measured by the `store.mjs` scalar cases), so the eviction sort compares strings with strings
and the next write of the fact quotes it. `lint` names it:
`fact 'hand-edit' in hand-edit.md: created is the unquoted timestamp 2026-01-01, read as
'2026-01-01'; quote it`. Only timestamps are coerced; an `int`/`bool` in those fields is left
exactly as the scalar cases pin it (`--suite store` PASS, §5).

(b) #122 — `compact` archives the FILE the fact was read from (`Fact.source`, set only by
the read), never `facts/<name>.md` derived from the frontmatter; the size table is keyed by
the fact object, not its name. `lint` names a mismatch:
`fact 'fresh-one' in stale.md: the file name does not match the fact name; rename the file to
fresh-one.md or the fact to stale`. The REPORT still lists the frontmatter name (wire shape
unchanged, `ArchivedFact.name`).

(c) #134 — the served description quotes the job46 formula and a worked example at the
default budget; `--reserve 0` is accepted by both CLIs (new `_nonnegative`, `must be >= 0`
on -1), the help text quotes the same default, schema minimum stays 0. The golden
`runtime-py/tests/data/served-tool-surface.json` is hand-edited in the same commit, as its
header requires (no regeneration command, on purpose).
