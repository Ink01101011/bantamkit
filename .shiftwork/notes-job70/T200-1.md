## Deviations from the plan text (property kept)

1. **`use_names` matches line by line, not with `re.MULTILINE`/`/gm`.** JavaScript's multiline `^` also starts a line
   after `\r`, U+2028, U+2029; Python's does not. Same regex body, anchored, applied to each `\n`-split line on both
   sides. Pinned by `use names … #06` (mutation M5 below).
2. **`touch:` line**: `touch: none` only when there is no touch directory AND no miss; else
   `touch: <n> missed write(s) (hook log)` through the existing `_plural`. The plan's literal (`none` whenever the touch
   dir is not a directory) would print `none` in exactly the forced-miss case (the touch path made a file).
3. **Retention** gets an `_old_touch`/`oldTouch` guard (fold only when a non-`folded` line is old), mirroring
   `_old_use`: a folded row keeps its old `ts`, so an unguarded fold rewrites the file daily and it never goes idle.
   Every touch log still goes through the idle-rotate path.
4. `touch_reducer` counts an integral float `n` as the integer (`JSON.parse` cannot tell `2.0` from `2`).
5. `next_seq` raises (both sides) when the state dir is unwritable; the hook arm turns it into one `touch: miss`
   record. The plan's "every fs error becomes 0" for Node would have appended a seq-0 line where Python appends none.
6. Node's `realpath` falls back to resolving the parent (as `os.path.realpath` does for a missing path).
7. TDD order: the Python tests were written after the module (Step 2's red run was not observed). The mutations below
   are the red evidence for the conformance cases.
8. Existing pins changed where the plan names the status line (all cite #200 / job70 T200-1, before→after):
   `test_status_surface.py` 12→13 lines (+ index shifts in the read-repair test), `test_storage_tiers.py`
   unreadable-home list (+`touch: none`); `server.test.mjs` 12→13, 14→15, 15→16 and row indexes +1 below the block;
   `storage-tiers.test.mjs` (+`touch: none`); `storage-tiers.mjs` block reader takes `touch` lines, all four expected
   blocks gain `touch: none`, case names `LITERAL: <s> storage block (#200 touch line) — <side>`;
   `docs/conformance.md` row + heading count; gate `WORDS` gains `thirty-two`.
