   by code point, not UTF-16.

4. Mutation N2 (Node does not re-save at Stop) reddens the TURN FILE, not the touch log: the first Stop's own
   `bash-turn` `write` line sits in `tail(session, from)` and explains the path at the second Stop. So the
   no-double-count property is held twice; the plan's "red: second-Stop bytes" is the turn-file bytes.
5. Extra symmetric mutation S2 (both open the turn after the skip), caught by the `/clear` turn literal.
6. TDD order: the Python tests ran red at collection (module absent) before the module existed; Node tests were
   written after the port.
