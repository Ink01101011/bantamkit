## Deviations
1. Manifest `docs` is the sorted NAME list (plan left it unspecified); needed so the manifest alone decides which
   segment owns a name (shadowing, crash safety).
2. Shard rows are `[name, segment_id, field, tf]`; plan's `sha256(term)[0] % 16` replaced by J69-3's `shard_of` (brief).
3. "compact keeps query results identical" holds for `(name, tf_sum)`; segment ids change by construction.
4. Scoring of archived hits is `tokenize_v2` tf_sum (the #199 tokenizer), not the live v1 word overlap; archived hits
   are ungated (min_ratio not applied to them).
5. `include_archived` reaches every layer's archive (profile too: `dream` archives there), read-only layers' failures skipped.
6. Python handler calls `recall_outcome(query, k)` unchanged when the flag is falsy (keeps `test_recall_k_clamped...`'s
   probe, whose signature has no new keyword, green without editing it).
7. Tests written after the code (honest order); red proven by mutation on copies.
8. Hook path untouched: the cold index is read only by an include_archived call.
