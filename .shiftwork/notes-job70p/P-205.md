## Deviations from the spec, resolved in the plan

1. **Multi-root core.** Spec gives the adapter three `roots`; `audit(root)` takes one. Summing per-root audits would
   miss a phrase shared across roots, so `audit_roots`/`scan_roots` (labelled) are added to the pure core; the tool's
   single-root contract and bytes are unchanged (guarded by the untouched `skillaudit` suite).
2. **Record fields.** Spec lists `{version, ts, host, catalogue_bytes, findings, surfaced}`; the plan adds `roots, skills,
   omissions, usage, proposals` (status line + report need them) and an `error` form (spec: "status says why").
3. **"Transcript line unreadable — skipped and counted, as tool-usage.mjs does".** tool-usage counts unreadable FILES
   and silently skips bad lines. Plan counts both: `unreadable` (files) and `skipped_lines` (candidate lines).
4. **Events-log fallback not ported** (spec names only id dedupe + subagents; the fallback reads a plugin's log).
5. **Non-string `input.skill` ignored** (JS `String(7)` vs Python `str(7)` would agree, but objects would not).
6. **mtime pre-filter** (not in tool-usage) — needed for the 2 s bar; a file last written before the cutoff holds no
   later line. `span_days` = min(30, now − oldest seen) where oldest = old-file mtimes ∪ candidate-line timestamps.
7. **Proposal needs ≥1 counted skill in the plugin** (else "every skill has zero calls" is vacuously true for LSP-only
   plugins like `gopls-lsp`). Grouped from counted skills, so this holds by construction.
8. **Diff format**: zero-context unified hunks (`@@ -N +N @@`) located by a line rule; minified settings → a sentence.
   Target file = the settings file whose `enabledPlugins` value won (user < project < local).
9. **Adapter choice** = `<home>/.claude` is a directory (precedent: tiers reads `~/.claude` for hook/host-data tiers).
10. **SessionStart placement**: Python last; Node before the node-only stale-install line, which keeps LAST (Q2.4).
    New log field `skillAuditBytes` on both sides.
11. **never-invoked on the SessionStart line only when span ≥ 30** ("just reached 30 days without a call").
12. **Prompt renders no timestamp** so the live prompt is byte-comparable without a mask.
