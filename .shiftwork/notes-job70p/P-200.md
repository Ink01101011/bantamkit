## Deviations from the spec resolved in the plan (each in the plan's "Spec deviations" section)

1. Weak-edge uses recorded by the HOOK into the touch log (`op: "use"`), not by the server into the usage ledger: the server has no session id or tool-call ordinal. (Q1)
2. `seq` = per-session count of every tool call in the repo, in `ledger-<session>.seq.json` (survives PostCompact; pruned by Retention's 7-day ledger rule).
3. bash-turn lines carry `from` (turn's start seq) for turn-granularity weak edges.
4. The graph has two fingerprints (strong: HEAD + git index stat + index-head prints; weak: touch-log size), so a touch does not re-run git.
5. `[via <file>]` is a SUFFIX on the header (a prefix breaks RECALL_HEADER).
6. Via fact appended after the k gated hits; the 700-byte cap drops it first. (Q2)
7. `VIA_ON = False` until gold pass 2 passes; `BANTAMKIT_VIA` overrides. (Q3)
8. "After compact" = SessionStart source=compact. (Q4)
9. `memory_recall` `required: []`, new error sentence for neither arg; with `file`, `query` ignored and said so. (Q5)
10. A bare ambiguous reference makes no edge; bare names without `/` or extension are not refs.
11. B commit window = [first touch, last touch + 1800 s].
12. Touch-log retention folds >30-day touch lines into one `folded` line per path; uses older than 30 days are dropped.
